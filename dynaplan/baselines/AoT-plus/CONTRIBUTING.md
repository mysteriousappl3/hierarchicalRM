# Contributing to AoT+

Thank you for your interest in contributing to AoT+! This document provides guidelines and instructions for contributing to this project.

## Getting Started

1. **Fork the repository** to your GitHub account
2. **Clone your fork** to your local machine
3. **Set up the development environment** following the instructions in the README.md file
4. **Create a new branch** for your contribution

## Types of Contributions

We welcome various types of contributions, including:

- **Bug fixes**: If you find a bug, please create an issue or submit a pull request with a fix
- **Feature additions**: New features that enhance the functionality of AoT+
- **Documentation improvements**: Updates or additions to documentation 
- **New planning domains**: Implementations of additional planning domains
- **Performance improvements**: Optimizations that improve the efficiency of the code
- **UI enhancements**: Improvements to the Streamlit interface

## Development Process

1. **Create an issue** describing the change you want to make
2. **Fork the repository** and create a branch with a descriptive name
3. **Make your changes**, following the coding standards
4. **Write tests** for new functionality
5. **Update documentation** to reflect your changes
6. **Submit a pull request** to the main repository

## Coding Standards

- Follow PEP 8 style guidelines for Python code
- Write clear, commented code with docstrings for functions and classes
- Include type hints where appropriate
- Keep functions focused on a single responsibility
- Write meaningful commit messages

## Pull Request Process

1. Update the README.md and other documentation with details of changes, if needed
2. The PR should work on Python 3.8 or higher
3. The PR will be reviewed by maintainers
4. Once approved, the PR will be merged by a maintainer

## Running Tests

Before submitting a PR, make sure to run the tests:

```bash
pytest
```

## Code Reviews

All submissions require review. We use GitHub pull requests for this purpose.

## Community Guidelines

- Be respectful of others
- Provide constructive feedback
- Help others learn and grow

## Questions?

If you have any questions, feel free to create an issue with the label "question".

Thank you for contributing to AoT+!
