# Frozen benchmark data

The JSONL files in this package are generated by `flat_hanoi.generate` and
frozen as benchmark inputs. Each adjacent `.manifest.json` records the exact
JSONL byte identity with SHA-256 plus generation, protocol, prompt, and scorer
identity metadata. It is an integrity record, not a cryptographic signature.

Run `python -m flat_hanoi validate PATH.jsonl` to verify schema, uniqueness,
profile counts, stored distances, and the required adjacent manifest hash. The
`--allow-missing-manifest` option exists only for inspecting ad hoc datasets;
paper-facing validation should never use it.
