# Robot Models

This folder contains the robot descriptions to build and import robot models into Unity or Mujoco

All code, projects, and assets found here are NOT to be redistibuted or reused without express authorization.

## Reference

The models found here are adapted from the following sources:

- [dvrk_env](https://github.com/WPI-AIM/dvrk_env) - dVRK description files and meshes
- [mujoco_menagerie](https://github.com/google-deepmind/mujoco_menagerie) - Franka description files and meshes
- [jhu-dvrk](https://github.com/jhu-dvrk/instrument-cad) - dVRK cad and mesh files

When possible, citations and reference should be given to the original sources, as without them this adaptation would not be possible.
